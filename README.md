# Pokemon-AI-Battle-System

## 專案說明

Pokemon-AI-Battle-System 是一個寶可夢影像辨識與前端對戰介面專案。後端使用 Python、PyTorch 與 TorchVision 建立參考圖片特徵資料庫，透過 cosine similarity 比對使用者輸入圖片，回傳最相近的寶可夢結果；前端使用 React、Vite、TypeScript、Tailwind CSS、Framer Motion 與 lucide-react 建立圖鑑、選角、載入與一般模式對戰介面。

## 功能摘要

- 讀取 `dataset/reference/` 內的寶可夢參考圖片。
- 使用 EfficientNet-B0 產生圖片 feature vector。
- 建立 `outputs/pokemon_features.npy` 與 `outputs/pokemon_index.json`。
- 對輸入圖片進行相似度比對並輸出 Top 5 結果。
- 提供 React 前端大廳、圖鑑、一般模式選角、載入頁與回合制對戰頁。
- 一般模式支援玩家與電腦輪抽三位夥伴後進入 1v1 回合對戰。

## 建立參考特徵資料庫

先將參考圖片放入 `dataset/reference/`，再執行：

```bash

```

輸出檔案：

```text
outputs/pokemon_features.npy
outputs/pokemon_index.json
```

## 一般模式對戰流程

1. 進入一般模式。
2. 玩家與電腦輪流選擇三位夥伴。
3. 玩家回合顯示「請選擇你的夥伴」並倒數。
4. 電腦回合顯示「對手正在選擇夥伴」並於指定秒數完成選擇與鎖定。
5. 雙方選完後顯示「準備戰鬥」並倒數 10 秒。
6. 倒數結束後等待 2 秒進入載入頁。
7. 載入完成後進入 1v1 回合對戰。

## 對戰介面規範

- 上方派出夥伴卡片只顯示角色圖片與名稱。
- 我方 HP 顯示於畫面左上，名稱在左上、數值在右上；敵方 HP 顯示於畫面右上，數值在左上、名稱在右上，HP 區域不使用卡片外框。
- 上方出戰卡片固定維持寬高 1:1.45，並與 HP HUD 保持距離避免遮擋。
- 上方出戰卡片內不顯示名稱或陣營文字，只保留角色圖片。
- 下方中央為固定高度技能操作區。
- 技能區左側顯示我方三張卡牌，右側顯示敵方三張卡牌。
- 下方卡牌固定貼近頁面底部，每張卡牌固定維持寬高 1:1.45，避免卡牌被壓縮或裁切。
- 備選卡牌保留角色圖、名稱、HP 與出戰狀態。
