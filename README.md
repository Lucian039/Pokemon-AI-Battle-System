## 專案說明

Pokemon-AI-Battle-System 是一個寶可夢影像辨識與前端對戰介面專案。後端使用 Python、PyTorch 與 TorchVision 建立參考圖片特徵資料庫，透過 cosine similarity 比對使用者輸入圖片，回傳最相近的寶可夢結果；前端使用 React、Vite、TypeScript、Tailwind CSS、Framer Motion 與 lucide-react 建立圖鑑、選角、載入與一般模式對戰介面。

## 功能摘要

- 讀取 `dataset/reference/` 內的寶可夢參考圖片。
- 使用 EfficientNet-B0 產生圖片 feature vector。
- 建立 `outputs/pokemon_features.npy` 與 `outputs/pokemon_index.json`。
- 對輸入圖片進行相似度比對並輸出 Top 5 結果。
- 提供 React 前端大廳、圖鑑、一般模式選角、載入頁與回合制對戰頁。
- 一般模式支援玩家與電腦輪抽三位夥伴後進入 1v1 回合對戰。

## 一般模式對戰流程

1. 進入一般模式。
2. 一般模式先進入匹配大廳，左側 3/4 顯示玩家一與玩家二對戰席，右側 1/4 顯示好友列表與準備按鈕。
3. 玩家按下「加入電腦」後，對手資訊更新為電腦訓練員，準備按鈕才可使用。
4. 按下「準備」後進入三局兩勝制，先拿下兩局的一方獲勝。
5. 每局選角區顯示目前所有 `enabled_battle` 可用角色，玩家與電腦輪流選擇三位夥伴。
6. 玩家回合顯示「請選擇你的夥伴」並倒數。
7. 電腦回合顯示「對手正在選擇夥伴」並於指定秒數完成選擇與鎖定。
8. 雙方選完後顯示「準備戰鬥」並倒數 10 秒。
9. 倒數結束後等待 2 秒進入載入頁。
10. 載入完成後進入 1v1 回合對戰，雙方第一隻出戰夥伴比較速度，速度較快者先攻；速度相同時隨機決定先攻，任一方三位夥伴全倒後結算該局勝負。
11. 若尚未有人取得兩勝，顯示本局勝方與目前比分，局間倒數後回到選角畫面開始下一局。
12. 若任一方取得兩勝，顯示最終結果與最終比分。

## 05/19: 新增攻擊提升三層疊加倍率
- 新增攻擊提升疊層規則：`attackBoostTurns` 作為攻擊提升層數使用，範圍為 0 到 3 層，成功施放 `raise_attack` 時增加 1 層並在 3 層封頂。
- 倍率規範：第 1 層為 `x1.50`，沿用目前攻擊提升顏色且只顯示「攻擊提升」；第 2 層為銀色並在框外顯示 `x1.65`；第 3 層為金色並在框外顯示 `x1.80`。
- 結算規範：攻擊命中且造成傷害時，一次套用目前層數倍率並清空攻擊提升；未命中或沒有造成傷害時不消耗層數。
- 平衡規範：不採用每層額外增加 50% 或乘算 50%，避免與屬性剋制、特性增傷、防禦降低等效果疊加後造成過高爆發。
- 輸出格式：技能說明顯示「攻擊提升 50%，可疊加至 x1.80」；戰鬥紀錄在攻擊提升發動時附上實際倍率，例如 `攻擊提升效果發動（x1.65）。`
- 視覺更新：第 2 層銀色標籤需有銀色掃光閃亮效果；第 3 層金色標籤需有金色掃光閃亮效果，用於強化疊層辨識。
- 05/19: 調整戰鬥 HUD 與換角 Buff 規範：敵方 HP 與體力條減少方向需與我方相反；備戰區卡片下方不得顯示 Buff 標籤；角色被換下時清除攻擊提升、防禦提升、速度提升與護盾等正向 Buff。
- 05/19: 攻擊提升倍率顯示規範：第 2、3 層倍率文字需顯示在狀態框外側，狀態框內只顯示「攻擊提升」，避免倍率文字被框線包住。
- 05/19: 調整攻擊與防禦提升徽章視覺：第 2 層徽章內部需使用銀色底與銀色閃亮效果，第 3 層徽章內部需使用金色底與金色閃亮效果，不只改外框顏色。
- 05/19: 新增防禦提升疊層規則：`defenseBoostTurns` 作為防禦提升層數使用，最多 2 層；第 1 層防禦倍率為 `x1.50`，第 2 層防禦倍率為 `x1.65`，受到傷害時以傷害除以防禦倍率後清空層數。
## 05/21: v3 規則一致化單局戰術與三局兩勝策略層

- 訓練 action space 擴充為技能、休息、普通攻擊、護盾、換牌，模型版本更新為 `battle-tactics-v3-rules`。
- 訓練引擎補上普攻、泛用護盾、休息、換牌與主要傷害/狀態/特性規則，讓訓練行為更貼近一般模式。
- Reward shaping 改為均衡戰術，提高合理換牌、休息、普攻、護盾的誘因，同時保留勝負為最高目標。
- 一般模式套用訓練模型時，電腦可實際執行新版 action，不再只支援技能、休息、換牌。
- 新增三局兩勝 `MatchStrategyPolicy` 架構，先以進攻/均衡/保守策略 bias 保留賽局訓練擴充點。
